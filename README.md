# Individuell examination – Git & Agilt (solo) 

## Bookmarks Mini

En enkel webbapplikation för hantering av bokmärken som byggt för den inviduella examinationen i kursen Versionshantering och strategier med Git.

### Funktioner

- Användare kan lägga till, ändra och ta bort bokmärken.
- Validering används för se till att titel och URL är giltiga.
- Användaren kan ändra ordningen i bokmärkeslistan.
- Bokmärkena sparas i localStorage och laddas när sidan öppnas igen

**Mål:** Visa ett helt Git-flöde (branches → PR → review → merge), lös minst 1 konflikt och skriv en kort reflektion om agilt (user stories, AC, DoD, förbättringar).
